# Posts Explorer

Приложение для просмотра и поиска публикаций.

Проект загружает данные с внешнего API и позволяет просматривать публикации с постраничной загрузкой, бесконечной прокруткой и поиском по содержимому. Данные подгружаются динамически без перезагрузки страницы.

## Возможности

* Получение данных через Fetch API
* Асинхронная загрузка публикаций
* Поиск публикаций в реальном времени
* Debounce для оптимизации поиска
* Постраничная загрузка данных
* Infinite Scroll через Intersection Observer
* Кнопка дополнительной загрузки записей
* Отображение состояний загрузки и ошибок
* Автоматическое прекращение загрузки при отсутствии данных

## Как работает

После запуска приложение загружает первую страницу публикаций из внешнего API и отображает их на странице.

Пользователь может искать публикации через поле поиска. Для предотвращения лишних запросов используется механизм Debounce, который отправляет запрос только после небольшой паузы во время ввода.

Новые записи могут загружаться вручную через кнопку или автоматически при прокрутке страницы благодаря использованию Intersection Observer. При достижении конца списка загрузка новых данных прекращается.
